##  Exercício 2

O programa utiliza estruturas de repetição `for` para mostrar:

* Os números de **1 até 50**, de 1 em 1.
* Os números de **52 até 100**, de 2 em 2.

### Conceitos utilizados

* `for`
* Variáveis inteiras
* `printf()`

##  Exercício 6

O programa recebe a quantidade de pessoas e, para cada pessoa, solicita:

* Sexo (`F` para feminino ou `M` para masculino)
* Altura

Depois, o programa calcula e mostra a **altura média das mulheres** e a **altura média dos homens**.

### Conceitos utilizados

* `for`
* `if`
* `scanf()`
* `printf()`
* Variáveis `int`, `float` e `char`
* Soma e cálculo de média

##  Linguagem utilizada

* **C**

##  Objetivo

Praticar estruturas de repetição, condições, entrada de dados, variáveis e cálculos básicos em linguagem C.
